# 面对浙大842考生的专业课做题网

[项目仓库](https://github.com/burriedalien666/zju842-practice) · [构建与测试](https://github.com/burriedalien666/zju842-practice/actions/workflows/check.yml)

按科目、题型和年份阅读原题，收藏、标记复习、组织题单。访客免登录，学习记录保存在自己的浏览器中。管理员可在题目下上传手写答案照片，保存草稿后发布；访客可以在站内提交文字纠错。

## 本地运行

安装 Node.js 24.14 或更新的 24.x 版本。在本目录打开终端：

```sh
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:8843 。这只是本机预览，公开服务需要部署到独立主机。

管理员密码通过交互终端设置，输入不回显：

```sh
npm run admin:setup
```

再次运行此命令可重置密码并退出所有已有登录。网页左下角进入管理员登录；登录后，每道题的“参考答案”旁出现“编辑照片答案”。未设置密码时不提供默认管理员。

需要更改配置时，将 `.env.example` 复制为 `.env`。启动和管理员设置命令会读取该文件。`.env` 不提交到 GitHub。

## 使用

- 用题源区分考研真题与期末试题；题型、年份和搜索可组合筛选。
- 顺序或随机练习使用当前筛选结果。收藏、掌握状态和题单刷新后保留。
- “分享”复制当前题目网址；接收者无需账号。
- “导出记录”下载 JSON 备份。“导入记录”确认后替换本浏览器记录。换设备、清理浏览器或更换网站域名前请导出。
- 旧网页与新网址属于不同存储空间；旧记录不会自动跨网址迁移。同源下检测到旧版记录时自动转换。
- 管理员可拍照或选多张相册照片，前后移动、旋转、替换、预览。每题最多12张、每张12MB。照片自动保存草稿，发布后访客才可见。修改草稿不改变已经发布的版本。
- “撤下公开答案”保留草稿，停止公开提供图片；无法收回访客此前自行下载的副本。
- 文字纠错只在管理中心展示，可标记已处理，不公开评论。

## 新增期末试题

继续提供整份 PDF 给维护者整理，不需要在网站逐题录入。PDF 保留在线下，整理后的题包只包含 `catalog.json` 和 `questions/` 下裁切题图。详见 [题库维护](docs/questions.md)。

```sh
npm run import:questions -- /path/to/prepared-package
npm run build
```

然后重启网站。导入只新增题目，不改已有题目编号及题图。

## 开发与检查

```sh
npm run build
npm test
npm audit
```

开发界面可另开终端运行 `npm run dev`。后端仍需运行，开发时将 `PUBLIC_ORIGIN` 设置为 `http://127.0.0.1:5173`，从该地址访问以匹配跨站请求保护。完成后恢复正式访问地址。

结构：`src/` 为界面；`server/` 为接口与 SQLite；`public/` 为题目索引和裁切图；`data/` 为私有数据库；`tests/` 为自动测试。没有前端云端密钥，也没有通用文件公开目录。照片在解码后转为 WebP，并去掉 EXIF 等元数据。
