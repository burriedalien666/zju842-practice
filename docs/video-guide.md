# 作者讲解链接维护

视频入口只发布作者整理的链接。普通用户仍可写自己的照片答案，但没有添加、修改讲解链接的界面或服务接口。

在源码 `web` 目录执行：

```sh
npm run videos
```

工具会依次询问：链接编号、关联单题(q)还是章节(c)、题号/章节编号、标题、B站链接，最后确认保存。题号可在刷题页点“复制题号”获得；选章节时工具会列出编号。相同链接编号可修改现有记录。

- 同一题可以关联多个讲解，使用不同链接编号。
- 链接可包含 `?p=2&t=90`，表示第2个分P、从90秒开始；实际跳转表现以B站客户端为准。
- 只接受完整的B站视频地址，不接收短链接、脚本链接或任意网站地址。
- 同一个整卷视频可关联多道题，各自填写不同起始时间。
- 列出链接：`npm run videos -- --list`。
- 移除链接：`npm run videos -- --remove`，按提示填写编号并确认。

工具只修改本地 `public/catalog.json`，不上传视频，也不自动发布。确认链接和素材后递增题库版本，通过题库更新发布；不用增加公共答案图片版本。发布流程仍由作者的GitHub仓库权限控制。开源用户能修改自己的源码副本，不等于能修改作者的官方发布。

目前没有作者提供的视频，页面不会显示空白讲解按钮。题库更新带来链接后，用户点击在新标签页打开，刷题页保留当前位置。
