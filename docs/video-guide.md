# 作者视频维护与分批导入

v0.5.6保持原来的章节和做题布局，只在已关联视频的题目下显示一个“视频”按钮。点击后仅列出这道题的作者讲解，不分题目/知识点/章节组，不推荐整章课程或其他作者视频。没有视频时不显示空入口。点击“跳转播放”在B站新标签页打开，原做题位置保留；整卷练习同样支持。

视频只由作者整理进公开题库；普通使用者没有修改官方视频链接的入口。开源用户可修改自己的副本，但不会改变作者发布的题库。

## 以后提供什么

提供你的**公开B站主页链接或UID**即可开始整理，不需要密码、Cookie或访问令牌。根据主页中的公开合集选择你录制的内容，核对原题号后导入。只有账号名不能保证精确定位；可附合集链接更直接。第三方视频仅用于独立验收，不加入正式内容。

支持普通BV视频页的多P选集，以及页面中完整提供的投稿合集。账号主页自动全量抓取、收藏夹、分批分页合集不在本轮自动读取范围。遇到验证、登录要求或目录不完整时停止自动读取，使用经浏览器核对的公开链接列表，不绕过验证。

## 分批工作流

在web目录中：

```sh
npm run videos -- --help
npm run videos -- --discover-url "https://www.bilibili.com/video/BVxxxxxxxxxx/" --out collection.json
```

第一步读取公开页面中的JSON标题和链接，不执行页面脚本，不下载视频、不读取登录数据。输出已存在会拒绝覆盖。

选集格式：

```json
{
  "format": 1,
  "title": "我的842讲解合集",
  "author": "作者公开名称",
  "items": [
    {
      "key": "stable-item-1",
      "title": "第1讲",
      "url": "https://www.bilibili.com/video/BV1234567890?p=1"
    }
  ]
}
```

示例BV为格式演示，不是实际视频。手工整理多个BV或主页投稿时可使用同一格式；key应稳定，重新排序不应改编号。

生成某一道题对应视频的批次，明确指定原题号。不同题目使用不同targetId；不要把整个合集自动挂到每道题下：

```sh
npm run videos -- --collection collection.json --prefix question-2009-1 --target question --target-id "2009|一|1" --from 1 --to 1 --out batch-1.json
npm run videos -- --import batch-1.json
npm run videos -- --import batch-1.json --apply
```

不带 `--apply` 只显示新增/修改/未变化数量，不写入。下一批可选择另一段视频并指定对应题号，或直接用items数组列出多道题的关联。批次只增补或修订本批条目，不清空以前的视频；重复导入不会重复添加。若同编号被用于另一个关联或视频，或用不同编号重复关联同一目标和链接，拒绝整批写入。无效条目不会留下部分导入。

作者维护工具只导入 `question` 目标，即精确原题号，例如 `2025|三|(1)`。多条链接只有在确实讲解同一道题时才关联在一起。旧数据中可能存在的章节/知识点视频不会自动进入本题列表，也没有章节视频入口。

不能仅凭标题推断视频讲了某道真题，关联前应核对内容。正式列表只放作者以后实录的视频，不将测试样例当成正式题目解析。

## 链接与分段

只接收完整B站视频链接，清理跟踪参数，保留 `p` 与 `t`。例如第2个分P的90秒为 `?p=2&t=90`。分段数据为：

```json
"segments": [
  {"title": "题意与方法", "seconds": 0},
  {"title": "计算过程", "seconds": 90}
]
```

分段时间需人工核实后填写，严格递增；不根据标题猜测时间点。实际播放、定位和登录要求仍以B站为准。

## 试验、副本和发布

所有命令可加 `--catalog <副本catalog.json>` 操作独立目录。本次公开视频样例只放在本地验收副本，不写进正式public。

引入分段字段时，工具会把最低程序要求提升至0.5.5；正式交付必须先发布兼容程序，再递增题库版本发布链接。视频元数据随**题库更新**下发，不属于公共答案图片更新；不能通过修改视频链接覆盖个人学习记录。

批量工具不会自动递增题库版本或发布GitHub。发布前核对实际关联、完整性和可访问性。历史交互单条模式继续支持 `npm run videos`、`--list` 和 `--remove`。
