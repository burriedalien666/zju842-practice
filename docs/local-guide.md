# 842 本地题库

解压整个文件夹后，Windows 双击“启动题库.cmd”；Mac 双击“启动题库.command”。浏览器会自动打开。无需安装 Node.js 或 Docker。不要在压缩包内直接启动。启动窗口需保持运行，关闭窗口即结束本次服务。

程序只监听本机，不把答案或学习记录上传到云端。已有题目、答案、收藏、题单和复习都能断网使用。源码仍可通过 `npm ci`、`npm run build`、`npm run desktop` 运行。

## 做题与完成进度

章节页支持“按解题任务”和“按具体知识点”。综合题可出现在多个知识点下，章节总题量仍按主章节去重。顶部“考点分析”可筛选科目、年份与知识点，点击格子进入原题，返回保留原统计条件。

章节和整卷均采用单题模式，左右按钮或方向键切题；顶部“选题”展开题号网格，也可输入当前练习序号。题卡右上角星星收藏，“更多”中加入／移出题单。参考答案点击后向下展开。

做题后选择“掌握”“不熟”或“不会”。**完成进度=已做题数／总题数**，例如3/23显示13%；三档自评都计一次已做，重复改评不增加题量。掌握题数另行显示，不代表自动判分。章节进度采用每题最近一次自评；整卷进度只统计当前这一轮，不带入上一轮成绩。旧版“已做”记录仍保留，但不推断为掌握。

目录“进度”开关控制分段条和数字显示；关闭后只留未开始／进行中／已完成状态圆点。浏览、收藏和打开答案不会自动变成已做。刚才的收藏或自评可在提示条中撤销；已有复习记录保留，不再把多种复习筛选堆在主界面。

“练习记录”可按年份回看每轮自评和原题；重新做一轮先保存上一轮，未做完的轮次也保留。计时可暂停或直接重置；重置不改自评、收藏或历史轮次。旧版没有保存的更早轮次无法重建，旧轮缺失的用时不补造。

日夜模式在顶部切换，题图保留原色。明显边缘留白会自动收起，查看图片时可以切回原图，原文件和私人答案照片不改写。

视频按钮每题保留，仅展示作者明确关联本题的讲解；未关联时提示待发布，有链接时在B站新标签页打开。考点分析分值栏“—”表示未标注，“*”表示部分已知；目前仅核实2025年分值，不把其他年份缺失计为零。

## 我的答案和题库答案

题库答案来自导入的资料包。“我的答案”只在自己的电脑保存，可导入多张图片、排序、旋转、替换。定稿只表示自己整理完成，不会自动公开。草稿也会保存。

“资料与备份 → 导出公开题库包”默认不包含个人答案。作者需要明确勾选希望公开的定稿答案，再生成 `.842pack`。导出包不带私人草稿、学习记录、密码或密钥。代码采用MIT，题目与答案素材遵循素材授权说明。

## 更新与备份

**正常使用内置更新不应清空已经保存的做题数据。** 程序文件与个人资料分开管理：

| 更新类别     | 修改内容                 | 对个人资料的处理                                                                   |
| ------------ | ------------------------ | ---------------------------------------------------------------------------------- |
| 程序更新     | 安装新程序并切换版本目录 | 保持原userdata路径；更新前备份SQLite数据库，新版启动失败时恢复旧程序与升级前数据。 |
| 题库更新     | 官方题目、题图及分类     | 保留旧题号和个人记录，不以题库包替换个人数据库。                                   |
| 公共答案更新 | 作者发布的参考答案       | 只替换公共答案，不替换“我的答案”、收藏或题单。                                     |

升级前先确认记录已保存，再从“资料与备份”导出一份完整备份，放到程序目录之外。自动备份也在原磁盘上，不能代替独立备份；误删userdata、硬盘故障或手动用旧备份覆盖仍可能造成损失。

手动解压到新目录后如果记录是空的，先核对是否仍在使用原userdata：新目录通常是另一份空白资料，不代表旧数据已被删除。保留原目录，不要拿新目录的空数据覆盖回去。“恢复个人资料”会替换当前资料，操作前另存现有备份。

v0.5.6起，程序内升级成功后会显示一次本次变更摘要；题库和答案更新后的刷新也会说明变化。点击“知道了”或关闭后不重复提醒，更新中心仍可回看。即使离线，也能查看程序自带的当前版本说明。手动迁移不会误报自动升级。

点击题图或答案可在窗口内查看完整图片；不再提供二次放大/缩小，避免横向和纵向来回拖动。

v0.5.2 会在页面使用期间检查本机连接，断开后持续提示。更新中心连接失败时可重新检查连接或导出本页记录；本地服务、启动会话和 GitHub 下载失败分别说明。重新启动时请使用**原程序目录**的启动器，在**同一个浏览器**打开生成的新页面；只输入旧网址不能恢复会话。若新旧页面端口不同，先保留未保存记录的导出文件，不要直接覆盖另一份资料。

页面会持续显示保存状态。发生写入失败时，本标签页暂存未保存的改动；关闭前请重试保存或导出。出现“连接已断开”时，重新启动题库，在新标签页打开启动器生成的链接，再回到原页面点“重试保存”，不要先刷新或关闭原页面。重试会先核对磁盘，既避免已保存的改动被误判失败，也不会覆盖其他标签页的新记录。暂存不替代个人资料备份，浏览器禁用存储时也可能不可用。

仅浏览考点分析的筛选不会修改学习记录；进入题目会保存“最近练习位置”，因此即使没有收藏或作答，服务断开后也可能出现未保存提示。请保持启动窗口运行；浏览器页面仍开着，不代表本地服务仍在运行。

同时打开两个标签页时，旧版本记录不能覆盖其他页面刚保存的数据。冲突时先导出本页改动，再选择“读取磁盘记录”；本版不自动合并。前后端升级后应刷新旧标签页，旧协议请求将被拒绝并提示刷新。恢复个人备份同样会使其他页面的旧版本失效。

顶部“更新中心”分为程序、题库和公共答案三个入口。启动时自动检查新版，仅提示，不自动下载或安装；可以取消“启动时自动检查”。自动检查复用六小时内结果，点击“检查更新”随时重新查询。

选择某一类的“查看并更新”并确认后，程序内完成下载和安装。题库与公共答案更新后刷新页面；程序更新会先备份个人资料、暂时停止写入，再启动新版。新版启动失败时自动恢复旧程序和升级前资料。更新时请关闭其他刷题标签页，等待完成，不要关闭启动窗口。

三个版本各自比较，题库或答案有变化不必重新下载整个程序。公共答案只替换作者公开的答案，不改变“我的答案”。若答案依赖尚未安装的题库，会先提示更新题库。新版目前没有公共答案，显示“无需更新”是正常状态。

下载仍需访问 GitHub，不能保证解决网络访问问题；失败会显示原因，可稍后重试，已有内容仍可离线使用。“资料与备份”保留手动导入 `.842pack` 和 `.842answers` 的入口。新版独立题库包不带答案；旧版混合题库包仍可导入，已安装独立公共答案包时优先使用独立答案。

个人数据在程序旁的 `userdata` 文件夹。关闭程序后，可以把整个程序文件夹复制到另一台电脑；跨系统时使用对应平台程序，将原 `userdata` 搬过去，或使用个人备份恢复。不要同时启动多个副本操作同一数据目录。

“备份全部个人资料”导出 `.sqlite`，包括照片、草稿、定稿和学习记录；“恢复个人资料”会替换当前个人资料，先保存旧备份。

### 升级程序

**v0.4.0及以后**：在更新中心确认程序更新即可，完成后继续使用原来的启动文件。新版程序存入程序目录的 `.app-versions`，个人资料仍在原来的 `userdata`；程序更新不会顺带升级题库或公共答案，需在各自入口确认。不要单独移动或删除 `.app-versions` 或 `.app-current.json`，复制便携程序时应复制整个文件夹。升级前个人备份保留在 `userdata/update-backups`，旧程序也会保留，占用一定磁盘空间。

**v0.3.0及更早版本，或手动升级**：

1. 在旧版确认记录已保存，使用“备份全部个人资料”保留一份备份，然后关闭旧版启动窗口和页面。
2. 从[最新发布页](https://github.com/burriedalien666/zju842-practice/releases/latest)下载对应系统的新版 ZIP，完整解压到新目录，不要覆盖旧目录。
3. 在新版尚未启动时，把旧程序旁的整个 `userdata` 文件夹复制到新程序旁；也可以先启动新版，再通过“恢复个人资料”导入上一步备份。两种方式选一种即可。
4. 启动新版，检查收藏、复习记录、题单和个人答案。确认无误前保留旧目录及备份，不要让新旧程序同时使用同一数据目录。

v0.3.0 会自动升级旧数据的保存版本信息，不清空个人资料。如需退回旧版，请使用升级前保留的旧目录和备份，不要让旧程序直接使用已经升级的数据目录。浏览器里仍打开的旧页面需关闭，重新通过新版启动器进入。

`.842pack` 和 `.842answers` 不更新程序；从 v0.3.0 升到 v0.4.0 需要手动下载一次新版程序 ZIP，此后无需反复去 GitHub 搬运程序包。源码运行模式不自动替换源码，开发者仍通过 Git 更新。

纠错入口前往 GitHub Discussions 的 Q&A。复制题号、题库版本和问题描述发帖，需要网络和 GitHub 账号；不会自动发送私人答案。

## 首次启动与系统提示

从项目正式发布页下载并核对版本。包按 Windows x64、Mac Apple 芯片 arm64、Mac Intel x64 分开提供。系统可能因下载的软件未经开发者商业签名而要求确认；请先检查来源，不要关闭系统整体安全保护。Mac 系统版本与芯片需符合所附 Node.js 24 的支持范围。

如果浏览器没有自动打开，请查看启动窗口的提示。Windows不要求管理员权限；Mac启动文件需有执行权限，发布ZIP会保留该权限。
