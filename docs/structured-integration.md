# 全题库结构化：本地接入记录

2026-09-26。用户已核验全部题面并授权迁移。本机接入完成后，v0.5.9正式发布沿用题库r4；具体功能见[版本说明](releases/v0.5.9.md)。

## 当前使用

继续双击原来桌面日常版中的“启动题库.cmd”，仍打开8843。旧安装文件夹名称可能仍为0.5.7，这是为了保留原入口；启动器会按内部版本指向运行0.5.8，不需要搬动或改名。

- 全部250组／469条记录默认显示结构化文字、KaTeX公式和SVG绘图，原图可展开对照。
- 43组／96条记录仍有来源疑点，记录没有删除，但不再阻止已核验稿显示。v0.5.9做题页不再显示原题说明或制作备注，只保留原图对照；疑点继续在维护文档中保存。
- 章节、整卷和历史回看共用题面，小问仍独立关联收藏、自评、答案和视频。
- 专题最后一题的右箭头打开“继续练习”：可进入下一专题，或展开选择其他专题。整卷末题右箭头打开本轮总结，不自动结束或评价。
- 目录高亮覆盖整个按钮，夜间颜色与主题一致；首页旧双栏分隔线已移除。
- v0.5.9移除章节卡片装饰图标和标题旁“已做／掌握”块，侧栏及章节进度仍可切换。

## 数据与版本

通过原启动器的程序安装、备份、激活流程升级，再通过独立题库导入接口安装r4。没有用隔离验证数据库替换个人数据库。程序升级前备份保存在原userdata的update-backups中，旧程序和原图保留。

本次对日常数据库的学习记录、私人答案及照片逐项比对，迁移及正常重启前后相同。原题ID、顺序和分类未改；公共答案仍按独立版本维护。

题库r4需要程序0.5.8或更新版本；旧截图题库仍兼容。若以后某题结构化显示需回退，可修改题库映射恢复原图，不回滚用户学习记录。
