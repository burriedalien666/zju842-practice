# 后续计划

更新日期：2026-09-20。当前正式程序版本为v0.5.7。

## 唯一暂定的新内容方向：题面结构化

将现在的截图题面逐步转成可排版的文字、公式、表格和矢量绘图，使长公式、波形、电路及芯片标注在不同屏幕上更清楚。

**当前只制定计划，不开始转换，也不开发新的渲染功能。** 详细阶段和验收方式见[题面结构化计划](structured-questions-plan.md)。开始样题或全库转换都需要另行确认。

## 持续维护

继续查找并复现程序、题库、公共答案三类更新及答案照片导入中的缺陷。检查使用临时资料和测试包，不修改真实个人资料，不向正式发布混入测试题或测试答案。

维护范围包括：

- 程序下载安装、同一启动入口重启、失败回退和资料保留。
- 题库新增／替换后的题号、分类、视频、公共答案依赖及个人记录兼容。
- 公共答案导出、发布索引、安装、替换及私人答案隔离。
- PNG／JPEG／WEBP答案照片导入、编辑、定稿、重启后读取。
- 新版本或相关代码改变后的回归；未变化且没有新风险时不重复跑全套测试。

## 暂停新增

不再把筛选标签、批量题单、答案并排、轮次对比、笔记、教材入口、手写、字号及年度题号方格表排成接下来的开发任务。已有功能继续保留，有具体Bug仍然修复。

通用题库框架和期末整卷模式目前仅评估可行性，不启动重构。未来提供期末试卷时，再根据资料、课程和卷别确定导入范围；本次不导入真实新试卷。

## 当前基础

已经具备章节／题型练习、整卷单题、题号跳转、三档自评、收藏与题单、计时、逐轮记录、日夜模式、个人答案照片、考点分析、视频入口，以及三类独立更新。

热力图功能已经完成；缺少依据的年份分值不补造。当前正式视频和公共答案内容仍待作者提供，不把内容待补充当成程序功能未完成。
