# 后续更新计划

本文件区分当前开发范围与后续设想；列入计划不代表已经实现，也不承诺发布日期。

## 当前范围：三类独立更新

目标：用户在程序内检查、下载并确认更新，不再需要每次打开 GitHub 发布页查找和手动搬运下载包。继续支持 Windows、Mac Intel 和 Mac Apple 芯片。

- **程序更新**：更新页面、功能和程序修复。
- **题库更新**：更新试卷、题目、题图和分类资料。
- **答案更新**：独立更新作者发布的公共题库答案，不改变使用者自己的答案、草稿或学习记录。

现有 v0.3.0 只能查询发布页及手动导入资料包，不具备自动替换程序的能力。旧版用户需要先手动升级一次到支持新更新机制的版本，之后才能使用程序内更新。

### 已确认的交互

- 在统一更新中心分别显示程序、题库和公共答案的本地版本、可用版本及更新说明。
- 下载和安装由用户确认；更新过程中显示进度和失败原因，不要求用户登录 GitHub 或提供访问令牌。
- 程序更新提示需要关闭并重启，更新前保留个人资料和可恢复的旧程序；下载或安装失败时保持旧版可用。
- 题库和答案分别更新；若新答案依赖尚未安装的题库，说明依赖，不将答案关联到错误题目。
- 保留手动下载与导入作为网络不可用时的备用方式。内置下载仍需要访问发布资源，不能保证绕过 GitHub 网络限制。

启动时自动联网检查新版，只提示，不自动下载或安装；提供关闭自动检查的设置，断网不影响刷题。同一资料目录的自动检查复用六小时内的结果，手动检查不受此限制。

## 后续设想一：历年真题章节热力图

目的：查看不同章节在历年真题中的考查分布，为复习安排提供参考。

期望内容：按章节和年份展示出现次数、分值等指标。

实施前需要明确：

- 出现次数按整道题还是小题统计；跨章节题如何归属，避免重复计数却不说明。
- 分值来自经过核对的题目标注；缺失分值显示“未标注”，不当作零分或自动猜测。
- 不同年份是否可比较，以及是否区分真题和后续新增的期末题。

状态：仅记录，本轮不实现；不将历史频次表达为未来命题概率。

## 后续设想二：B站讲解视频入口

目的：作者未来发布讲解视频后，使用者可从相关题目或章节跳转观看。

实施前需要明确：

- 视频与单题、整张试卷或章节的关联方式；是否允许一题多个视频。
- 是否标注讲解片段的起始时间，方便直接找到对应内容。
- 没有视频时如何展示入口；仅外链跳转还是需要其他展示方式。

状态：仅记录，本轮不实现。尚未提供的视频链接不预填、不虚构；不包含视频下载、搬运或自动发布。
