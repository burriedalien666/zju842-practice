# 后续更新计划

这是项目唯一的计划正文。本地“专业课”文件夹根目录的“后续更新计划.md”只提供入口，避免多份计划不同步。

状态按 **v0.5.6** 整理，区分已实现功能与待提供内容。

## 一、程序、题库、答案三类独立更新

**已实现。** 更新中心分别显示三个版本，用户确认后下载安装；启动自动检查只提示，可关闭。保留手动下载/导入，个人答案和学习记录不随公共资料更新被覆盖。

v0.4.0加入内置更新，v0.5.4补充代理连接、失败重试、诊断和安装恢复。旧版无法连接下载源时，需要按[恢复与迁移](old-version-recovery.md)完成一次性过渡，不代表旧客户端能自动获得尚未安装的修复。

**仍需按实际反馈验证/维护：**

- 不同系统与网络下的更新体验，失败原因、重试与恢复。
- 每次真实发布后的程序包、题库和答案兼容性。
- 下载仍依赖GitHub网络；不承诺支持所有代理或网络环境。

具体功能与已知边界见[v0.5.4说明](releases/v0.5.4.md)和[更新网络](update-network.md)。

## 二、历年章节／知识点热力图

**已实现第一版。** v0.5.0加入年份矩阵、排行、趋势及点击跳题；v0.5.1简化筛选与章节下钻。参考的是历年命题分布，不是每日打卡图。

**尚待补充：**

- 继续从原卷核实其他年份的分值；当前仅2025年已录入明确分值，缺失值不当作零分或擅自均分。
- 根据实际做题反馈完善知识点标注，尤其综合题涉及的多个知识点。
- 后续新增其他题源时与考研真题分开统计，不把历史频次写成未来命题概率。

口径：综合题可标多个知识点，但这些行的次数不能直接相加；章节总题数按既定去重口径计算。分类依据本地考纲与教材，具体见[842考点分析设计](analysis-design.md)。

## 三、B站讲解视频入口

**功能已完成并随v0.5.6交付，实际作者视频待提供。**

保留原有章节/题型页面；只在做题页增加“视频”按钮，列表只显示本题明确关联的作者讲解，不按知识点/章节分组，不推荐整套课程。支持分P和起始时间。视频只由作者维护并发布；没有实际链接时不显示空入口。

本地新增：公开多P/合集元数据读取，按原题号生成批次，预览后确认写入和重复导入去重。第三方样例只用于独立测试；正式内容只收录作者未来实录的视频。提供作者公开主页/UID后选择合集并核对原题号，不需要登录凭据，不自动猜题号或导入整个账号。

后续由作者发布真实讲解视频后，补充关联并随资料更新。此计划不包含下载、搬运或自动发布视频。使用方法见[视频维护](video-guide.md)。

## 四、后续功能与界面完善建议

见[按优先级排序的建议](next-improvements.md)。建议先做操作区统一、误操作撤销和视觉密度整理，再考虑轻量笔记、错因与题单优化。该清单仅供选择，尚未启动开发；不重复重做已实现的热力图、整卷或复习模块。

已确认下一步先进行需求澄清，再决定“操作区统一、误操作撤销、UI密度”的具体实现。本轮不直接启动该轮开发；题面文本/公式/SVG化另行讨论。
