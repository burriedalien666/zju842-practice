# 后续更新计划

更新日期：2026-09-20。本文是唯一的后续计划正文；专业课根目录的“后续更新计划.md”仅作为入口。当前正式程序版本为v0.5.7。

## 第一更新计划：先做题面结构化样题

**计划已确定，尚未开始执行。** 先选5—10道代表题，将题干转为文字、公式、表格和可缩放绘图；样题通过核对后，再决定如何分批转换全库，不直接启动整库转换。

样题覆盖普通文字、复杂公式、分段函数、表格、波形／频谱、逻辑门、状态图和芯片电路。保留原图对照，核对符号、单位、引脚和连线，原题号及学习记录不变。

按“样题制作 → 内容与显示核验 → 测量工作量 → 确认批量方案”的顺序推进。详细步骤见[题面结构化样题方案](structured-questions-plan.md)，它是本计划的实施说明，不是第二份独立计划。

## 每次修改后的自检

“持续自检”指每次修改后检查，不是定时任务；不安排每天或按小时运行。

- 每次程序、题库、公共答案、维护工具或更新逻辑的小更新后，执行相关回归，并核对三类更新及答案图片导入是否仍可用。
- 三类更新检查覆盖版本判断、依赖、安装、重启／回退，以及收藏、自评、题单、轮次和私人照片保留。
- 答案图片检查覆盖导入、编辑、定稿、导出所选公共答案、另一用户导入及私人资料隔离。
- 纯文档修改检查链接、页面内容和计划一致性；不把文字检查冒称为程序回归。
- 正式发布前执行完整发布检查；检查失败先修复，不以“改动很小”为由跳过。
- 全部检查使用临时目录、测试包和合成资料，不拿用户真实userdata试错，不公开测试题或答案。

## 已有功能与暂缓事项

已有章节／题型练习、整卷单题、题号跳转、自评、收藏与题单、计时、逐轮记录、日夜模式、个人答案照片、考点分析、视频入口和三类独立更新继续保留，有明确Bug继续修复。

筛选标签、批量题单、答案并排、轮次对比、笔记、教材、手写、字号和年度题号方格表，暂不新增。视频与公共答案由作者提供实际内容后再单独发布；没有内容不等于功能未完成。

未来提供期末试卷后，可先按题追加到当前两科；期末整卷分组、新增科目等范围另行确认。本次不开始导入真实期末卷。

## 末尾备选：通用题库框架

先记录，不排期、不实施，不抢占样题计划。未来可考虑“可配置底座＋内容格式说明＋AI整理指引＋可运行样例”，让其他维护者用自己的试卷生成类似题库。

需要处理科目与分类、项目身份和个人数据隔离、独立更新源、试卷分组及内容导入。做成可配置底座属于中等规模重构；任意扫描试卷一键形成准确的文字、公式与电路题库仍是大工程。

范围和工作量分析见[通用框架与期末题说明](reuse-and-final-exams.md)。是否启动，等题面样题结果和实际需求明确后再决定。
