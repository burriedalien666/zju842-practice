# 将电脑版资料迁入安卓App

适用于安卓1.0.4及以上：[下载安卓安装包](https://github.com/burriedalien666/zju842-practice/releases/download/android-v1.0.4/842-tablet-1.0.4.apk)。原电脑版是通过启动器打开的离线版；已有“备份全部个人资料”功能的版本无需升级即可导出。

## 操作步骤

1. 在电脑上通过原启动器打开842刷题，进入“资料与备份”，点击“备份全部个人资料”，保存生成的 `842-personal-backup.sqlite`。这份文件包含个人答案照片和学习记录，请保存好。
2. 将文件通过数据线、微信文件传输等方式传到安卓设备。不要上传到公开仓库、Issue或群文件。
3. 安装安卓1.0.4或更高兼容版本；已安装App时覆盖更新，保留原App资料，不卸载、不清除数据。升级前可在App“资料”中先备份。
4. 打开App“资料 → 从电脑版迁入 → 选择电脑备份”，选择刚传来的 `.sqlite` 文件。
5. 核对资料数量和冲突清单。默认保留App已有的冲突内容；选择“采用电脑内容”会替换清单中的冲突项。确认后新增资料加入App，相同资料跳过。
6. 迁入后抽查照片、题单与历年练习记录，在App中再备份一次，然后继续做题。电脑原资料和导出的文件都保留。

旧“导出记录”生成的学习记录 `.json` 也能从同一入口迁入，但该文件本身不含照片。要带走个人答案照片，请使用完整 `.sqlite` 备份。

## 迁入内容如何显示

- 收藏、自评、题单和整卷记录迁入对应位置。电脑版“已掌握”对应绿色；仅有“待复习”标记、没有更细自评的旧记录对应黄色，原始标记另行保留。
- 未结束的当前试卷可以在“历年真题 → 练习记录”继续，保留原题目范围、自评和已有累计用时。
- 电脑版已归档但没有结束时间的历史轮次显示“已归档”，保持只读；不会把归档时间伪装成完成时间。
- 没有完整用时的旧记录会注明“原用时未完整记录”。显示值仅代表已保存的累计时间。
- 同题的草稿照片在前，定稿中独有的照片接在后面；相同照片编号只迁入一次。草稿／定稿归属、复习计划等电脑原始记录随App备份留存。App不执行电脑版专属的复习计划。

同名题单、同题学习标记、已迁入后又修改的照片或同一轮次，可能出现冲突；先核对清单再确认采用哪端内容。一个迁移窗口中选择的处理方式适用于全部冲突项，不会删除清单外的App资料。重复导入同一文件不会重复添加相同资料。

## 需要处理的提示

- **题号不在本机题库**：先更新App题库或核对备份来源，再重新选择文件。迁移文件只包含私人资料，不代替题库更新。
- **照片超限**：每题最多12张，单张最多12MiB。草稿与定稿合并，或与App已有照片合并后超限时，本次导入不提交。先保留原备份，再整理对应题目的照片；不会自动截掉图片。
- **题单超限、文件损坏、暂存失效或空间不足**：原App资料保留；按提示处理后重新选择。读取和写入大文件都需要设备有足够空闲空间。
- **只有JSON文件**：可以迁入学习记录，照片不会由JSON补出来，也不会因此清空App已有照片。

迁入了电脑原始记录、每题超过6张照片或单张超过8MiB照片后，App生成的备份使用format4，需要1.0.4及以上兼容版本恢复。1.0.4继续读取之前的format1—3备份。请保留原电脑备份，避免回装旧App来处理新版资料。
