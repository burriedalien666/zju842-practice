## 本轮采用的界面规则

- 简洁来自按需展开，不靠缩小正文、压缩所有间距。
- 做题主界面保留星形收藏和唯一一组“掌握／不熟／不会”，不重复摆放待复习、掌握等按钮。
- 目录、章节卡片、学科概览和整卷完成进度均以全部题目为分母，3/23显示13%；掌握题数单独标注，未做完不显示100%。开关关闭只保留未开始／进行中／已完成状态圆点。浏览、收藏或查看答案不等同于完成作答。
- 视频仅指向本题明确关联的作者讲解。未发布时说明状态，不隐藏入口，也不放演示视频或虚假链接。
- 题图只收起明显边缘留白，保留安全边距及原图。私人答案照片不自动裁剪，公式和电路不重绘、不反相。
- 计时重置一按归零，不弹确认框，不改自评、收藏或历史轮次。
- 不增加提示、笔记、教材、手写、字号入口及年度题号方格表。保持原题号、学习资料和章节结构。

## 接下来按什么顺序推进

**v0.5.7之后继续先完善已有体验。** 优先处理实际碰到的显示、返回、保存和统计问题，不在修界面时顺带增加模块。

可从以下候选中选择下一轮；以下尚未授权开发：

1. **筛选和题单更省操作。** 显示可单独清除的筛选条件，讲清零结果原因；增加当前筛选结果批量加入题单、题单内批量移出。范围和返回位置保持一致。
2. **个人答案阅读更方便。** 改善多张照片的顺序浏览；在宽屏下尝试题目与答案并排，窄屏自动上下排列。保持现有适窗查看，不恢复已取消的复杂缩放条。
3. **逐轮记录查找与对比。** 先按年份、轮次筛选和定位题目；若确有需要，再比较同题在不同轮次的自评变化。自评变化不包装为客观成绩。
4. **题面结构化小样。** 另行确认后，用5—10道代表题验证“文字＋公式＋原图／SVG”的混合方案，再评估全库工作量。当前不进行整库OCR或公式迁移。
