# 源码审查与本地启动

源码审查包保留前端、后端、依赖锁文件、构建脚本、测试及可公开的题库资料，用于独立审查和复现交互。源码与免安装发布包分开更新，请以各自的版本和提交记录为准。

## 运行

需要 Node.js 24.14 或更新的24.x版本。在源码根目录执行：

```sh
npm ci
npm run build
npm run desktop
```

使用启动器自动打开的页面，不要直接双击 `index.html`。启动器只监听本机，并自动建立本机会话；首次生成 `userdata`。该目录不在源码包中。无需 `.env`、Turso或Render账号。

开发前端时可以使用 `npm run dev`，但本地完整交互验证优先使用上面的构建和启动流程。在线服务模式另见 `docs/deployment.md`，不是此次审查的必需条件。

## 检查

```sh
npm test
npm run test:desktop
```

测试不读取真实 `.env`，数据库和照片测试使用临时目录、人工图像。`public/catalog.json` 与 `public/questions/` 是原项目已公开的题目索引及裁切题图，不含原PDF、整页扫描或私人答案。

`tests/fixtures/interaction-study.sample.json` 是人工构造的收藏、待复习、到期和题单记录，引用公开题号，不是任何人的真实学习资料。在独立测试实例中使用“导入记录”载入；导入会替换该实例的学习标记，请勿用于日常学习实例。也可以把 `ZJU842_DATA_DIR` 指向一个新目录后启动。

## 交互检查重点

- `src/interactions.js`：取消单项标记、移出当前列表、移除后的选题与队列修正。
- `src/main.js`：章节切换、空列表入口、过滤条件、刷新/浏览器返回时的导航上下文、个人答案与整卷操作。
- `src/navigation.js`：显示当前学习范围、空章节重新选择和返回、章节题数。
- `src/review.js`：暂停到期提醒时保留历史计数；重新自评后恢复复习安排。
- `src/papers.js`：整卷本轮标记与全局学习标记分开，倒计时的日期边界。
- `server/local.js`：本地身份校验、资料备份恢复、题库包导入不覆盖个人资料。

复现路径：人工样例导入 → 待复习 → 移出第一题 → 移出最后一题；然后分别从收藏、错题重做、到期复习、已掌握、题单进入“切换章节”，选零题章节，再重新选择、返回列表、清除筛选、切换学科、刷新。注意“取消待复习”只取消手动标记；“暂停这题复习”停止到期提醒；“移出错题”仅取消未解决错题状态，不删除历史错误次数或答案。

## 包内与包外

包内含 `package.json`、`package-lock.json` 和无密钥的 `.env.example`。不含 `node_modules`、`.git`、真实 `.env`、`data`、`userdata`、运行日志、云端访问密钥、管理员密码、个人答案、历史草稿或下载的发布包。

独立审查可重点检查跨标签页同时修改记录、备份与题库包输入校验，以及各操作系统上的启动和使用流程。
