# 842刷题安卓版

[下载1.0.3安装包](https://github.com/burriedalien666/zju842-practice/releases/download/android-v1.0.3/842-tablet-1.0.3.apk) · [发布说明](releases/android-v1.0.3.md) · [完整安卓源码](https://github.com/burriedalien666/zju842-practice/releases/download/android-v1.0.3/842-tablet-1.0.3-source.zip)

安卓App内置2009—2025年浙大842题库，安装后不需要电脑持续开机。做题记录、收藏、题单、轮次和个人答案照片自动保存到设备，断网仍可刷题。联网可检查更新、打开视频及软件反馈。

## 安装与升级

- **首次安装**：下载 `842-tablet-1.0.3.apk`，在安卓文件管理器中打开，按系统提示安装“842刷题”。仅为用于安装的文件管理器授予必要的安装来源权限。
- **已安装1.0.x**：先在“资料”中备份，再通过“程序更新”或文件管理器覆盖安装。已安装1.0.3时无需重复安装。
- **从0.4.x测试版迁入**：先备份，再用文件管理器打开APK覆盖；旧App内置更新器只接受证书完全相同的包，会拦截首次正式签名轮换。**不要卸载旧版或清除数据。**

如果系统拒绝覆盖或提示签名不兼容，保留原App和备份，反馈具体提示，不通过卸载绕过。正式版以后复用长期签名；不建议回装旧测试版，问题应通过更高版本修复。

最低支持Android7.0（API24）；实际运行与覆盖测试在Android11、Android15模拟器完成。Android9及以上使用正式证书及签名轮换记录；7/8保留兼容签名并完成签名校验，尚未补充旧系统运行实测。

## 日常操作

- 按章节、历年真题、考点、收藏和题单进入练习；做题页可切题、选题、自评、收藏和查看原图。
- “我的答案”可从相册添加或拍照，支持旋转裁切、排序及最近一次删除撤销。每题最多6张、单张8MiB，照片全库容量受设备可用空间影响。
- “历年真题 → 练习记录”先选年份，再看该年各轮时间、自评和每题情况。已结束轮次只读，未结束轮次可继续。
- “资料 → 关于842”可查看作者、仓库、Star和软件意见反馈；题面问题使用题目菜单里的“题目纠错”。反馈由用户确认提交。

## 备份与更新

在“资料”中点“备份”留一份额外副本；Android10及以上默认保存到“下载／842备份”。恢复前会显示摘要，确认后以备份内容替换本机资料。重要备份可分享或另存到你控制的位置。卸载或清除App数据前务必先备份。

程序、题库和公共答案分别更新。安卓程序采用APK，题库采用 `.842pack`，公共答案采用 `.842answers`；个人照片与公共答案分开保存。内容更新不覆盖私人资料。网络失败可重试或从文件导入，未安装成功前保留当前内容。

当前题库r4，共250组／469条题目、287张原图；公共答案r0，暂无正式答案和视频讲解。期末卷实际收录后才显示按卷入口。

安卓与电脑版不自动同步，个人备份不能直接互换。软件问题可在[Issues](https://github.com/burriedalien666/zju842-practice/issues)反馈；请勿上传私人备份或答案照片。
