# 842考点分析设计

## 已确认范围

- 参考 `https://www.408os.cn/analysis` 的真题数据分析，不是每日刷题打卡图。
- 具体知识点必须结合本地考纲、教材及842原题建立，不照搬408知识点。
- B站讲解链接仅由作者维护并发布，不提供普通用户添加或修改视频链接的界面。
- 不变更既有题号，不因调整分类丢失个人答案、收藏或复习记录。

## 分类依据

1. 本地 `842考试大纲.doc` 正文明确为《信号系统与数字电路》（842）、2024年统考适用，信号系统与数字电路各75分。作为本轮主依据，不冒称2026/2027最新考纲，也不把该分配强加给所有历史试卷。
2. 于慧敏等《信号与系统学习指导》，已核对PDF第6—7页目录：前七章对应概念、时域、连续频域、离散频域、采样调制、拉氏、Z域；后续系统函数内容按连续/离散对象归入对应章节，状态变量内容单独判断范围。
3. 阎石《数字电子技术基础》第六版，已核对PDF第17—21页相关目录：数制、逻辑代数、门电路、组合逻辑、半导体存储、时序逻辑、脉冲波形。划线只是所提供副本中的学习标注，不能取代考纲。
4. 逐题映射时还需看原题，不将题型名称自动当成准确的细知识点标注。教材原图、全文和答案不因本次参考而加入公开项目。

## 建议层级：科目 → 章节 → 知识点 → 题目

知识点采用具体概念名称，题型作为独立标签保留。例如“拉普拉斯收敛域”是知识点，“由零极点判断因果稳定”是题型；两者不混成同一级目录。

### 信号与系统（建议七章）

| 章节 | 细知识点示例与范围 |
| --- | --- |
| 信号与系统基础 | 冲激/阶跃/复指数信号；周期、奇偶与能量功率；自变量变换；线性、时不变、因果、稳定与记忆性 |
| LTI系统时域分析 | 卷积积分、卷积和及性质；冲激响应与阶跃响应；零输入/零状态/完全响应；微分/差分方程；时域系统框图 |
| 连续时间频域分析 | 特征函数；傅里叶级数；傅里叶变换对与性质；幅相频谱；频率响应；理想滤波与无失真传输 |
| 离散时间频域分析 | 离散特征函数与周期性；DTFS；DTFT及性质；频率响应；离散滤波。DFT等另核实其考纲关系，不将DTFT与DFT混写 |
| 采样、调制与通信 | 连续采样与重建；欠采样与混叠；离散采样；抽取与内插；连续系统的离散实现；幅度调制与频分复用；脉冲幅度调制与时分复用 |
| 拉普拉斯变换与连续系统 | 双边变换、变换对与性质；收敛域与零极点；反变换；单边变换与初始条件；系统函数、响应、因果稳定与实现 |
| Z变换与离散系统 | 双边变换、变换对与性质；收敛域与零极点；反变换；单边变换与初始条件；系统函数、差分响应、因果稳定与实现 |

| 章节 | 细知识点示例与范围 |

## 已确认的统计与交互

- 总览：题量、收录年份、已有真题覆盖的知识点数、分值标注覆盖率。
- 章节/知识点与年份矩阵：切换题量、考察与否、已核实分值；点击格子进入对应题目列表，返回时保留年份与章节筛选。
- 分开显示题量与考察年数，例如某年出现3题，计3题但只计1个考察年份。
- 排行与趋势：可选全时段/近五年/自定年份，分科统计，不把期末题混进考研频次。
- 统计单元拟采用可独立归类的题目或小题；保留原卷大题关系，同一大题总分不重复分配到每个小题。
- 跨知识点题保留多个考点标签，知识点“涉及题数”可重复命中，明确不可直接相加；章节总题量按题号去重，主章节口径用于可加总报表。
- 分值只采用原卷可确认的总分/小题分值；不能分摊时显示“综合题共享分值/未拆分”，不均分、不估算、不将缺失计为0。
- 历史趋势只描述实际统计，不采用参考页中的“去年没考今年概率更高”等预测结论。

## 视频入口

建议单题和章节均可关联作者的B站链接，支持分P与起始时间；同一整卷视频可关联多题的不同时间点。有视频才显示“视频讲解”，点击新标签页打开，原刷题位置保留。不内嵌播放器、不下载视频、不使用第三方网站的视频冒充作者讲解。

## 已确认及本版实现边界

用户已确认综合题标注多个知识点，并授权重设计具体训练题型。v0.5.0按本方案实现18章、97知识点及52类训练任务。

当前知识点标注由既有题干摘要、标签、题型及部分原题核对整理，不声称已经逐题核对全部原卷。分值目前只录入2025年原卷明确给出的27个条目，合计150分；其他年份不估填，后续可继续补充。知识点涉及分值不是各知识点的独立评分分配。

作者视频采用独立维护工具写入公开题库索引，随题库更新传播；没有普通用户编辑接口，没有预填或虚构视频链接。
