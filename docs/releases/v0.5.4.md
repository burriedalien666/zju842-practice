# v0.5.4：三类更新的网络适配与安装恢复

本次更新程序功能，题库保持 **r2（469题、287张题图）**，公共答案保持 **r0**。演示用的2道原创题和解析不进入正式题库。

v0.5.3仅用于本地审查和用户验收，没有公开Release。正式版使用v0.5.4，让已安装同号验收版的用户也能通过更新中心发现本次最终修复。

## 本次具体工作

### 更新下载与网络

- 程序、题库、公共答案共用新的下载实现：优先使用已配置的HTTP/HTTPS环境代理，没有环境代理时读取Windows/macOS静态系统代理，没有配置代理才直连。
- 不修改系统代理，不要求GitHub令牌，不使用第三方镜像；遇到不支持的PAC/WPAD、仅SOCKS代理或代理认证时明确说明，不擅自切换直连。
- 可重试连接故障最多尝试3次，中断后清理本次残缺文件并从头下载；对HTTP状态、TLS、DNS、重定向、清单及CDN分别给出错误阶段。
- 拒绝HTML错误页、错误长度、非ZIP内容及不可信下载地址。
- 大包下载总时限从10分钟延长到30分钟，保留30秒空闲时限；界面等待更新结果的时限同步为32分钟，避免慢速但仍有进度的下载提前结束。
- 新增脱敏诊断导出，包含代理来源、平台和错误码，不包含代理地址/密码、启动令牌、个人照片或学习记录。

### 安装、内容与数据保护

- 修复确认题库r3后，并发检查可能将实际安装目标替换为r4的竞态；安装开始时保留本次确认的目标。
- 修复下载目录创建失败逃出任务异常处理，以及可选缓存JSON损坏阻断本地初始化的问题。
- 为同一次安装确认关联请求标识；响应丢失先查询任务状态，避免盲目重复安装，轮询只确认对应任务。
- 补齐服务关闭/重启期间先返回HTTP 503的状态：显示本机暂不可用和恢复步骤，保留未保存改动，不再泄漏笼统英文提示或误称GitHub下载故障。
- 手动和在线题库/答案更新统一检查版本、程序/题库依赖、既有题号和图片引用；拒绝不兼容内容，保留个人收藏、复习、题单、整卷进度和私人答案。
- 内容导入、导出和恢复与个人写入互斥；中断请求不会提前放开仍在执行的操作。
- 完整解码题图/答案时复用内存字节，修复Windows下图片文件被占用，导致失败目录无法删除的问题。
- 清理失败不再掩盖原始安装错误；分别报告磁盘错误和清理未完成，保留已激活目录及旧版资料。

### 测试与维护

- 修复桌面升级夹具混入运行锁文件的问题，并在任务失败时报告具体原因，不再只报笼统超时。
- 增加网络故障、非空公共答案、题库新增题、迁移失败、Windows图片释放与真实Fastify导入错误测试。
- 增加真实Chrome中的题库/答案更新、刷新及数据保留回归；这部分仅将发布传输替换为人工更新源，HTTP接口与实际安装不替换。
- 保留自动化回归测试；临时人工演示服务和测试资料不进入源码交付或正式发布包。

## 验证与网络边界

本机Node24.15.0与锁定依赖下，161项自动化测试通过；Chrome断连恢复、7个更新UI场景、题库/非空答案的真实界面安装通过。Windows免安装包的启动、旧启动器激活、照片/记录保留与损坏版本回退通过。三平台构建与程序包启动/回退由对应发布流水线执行，具体记录可从本版本提交的Actions查看。

程序激活/回退及内容更新回归使用受控发布传输，不应写成所有公网升级已经验证。仅Windows系统代理下，公开题库和答案完整下载成功；本地验收期间公开程序大包曾在旧10分钟时限下超时，不能因延长时限就承诺所有弱网都成功。正式发布后的公开Windows包升级结果单独记入本版本发布记录。

PAC/WPAD、仅SOCKS代理、NTLM/Kerberos自动登录不支持；不会关闭TLS验证来绕过企业证书问题。本次不提供断点续传。

## 下载与升级

- Windows x64、Mac Intel x64、Mac Apple芯片arm64分别选择对应ZIP，解压后双击“启动题库”。无需另装Node.js。
- v0.4.0及以后免安装版，旧下载链路可用时可以通过更新中心升级。完成后继续使用原启动文件；程序升级不会自动替换题库或公共答案。
- **旧版本身下载失败时，不会自动获得新版的网络修复。** 请用浏览器下载完整v0.5.4包，解压到新目录；先保存/备份并停止旧实例，再复制整份userdata或恢复个人备份。保留旧目录和备份，不覆盖正在运行的目录。
- 源码ZIP不是免安装程序。题库包和答案包也不包含程序功能升级。
- 本地验收版v0.5.3用户可以点击“检查更新”升级到正式v0.5.4，原资料目录保持不变。
