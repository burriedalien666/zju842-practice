# v0.4.0：程序、题库、答案独立更新

新增程序内更新中心，分别管理程序、题库与作者公开的答案。

- 启动时自动检查新版，仅提示；点击确认后才下载和安装，也可以关闭自动检查。
- 程序更新在本机下载、保留旧程序、备份个人资料并重启。新版无法启动时自动恢复旧程序和升级前资料。
- 题库与答案独立版本、独立下载，公共答案不覆盖“我的答案”、草稿、收藏或复习记录。
- 显示下载进度、失败原因和更新依赖，保留离线刷题与手动导入入口。
- 后续计划新增章节历年真题热力图及B站讲解入口；这两项本版未实现。

## 下载和升级

Windows x64、Mac Apple芯片和Mac Intel各自选择对应 ZIP，完整解压后双击启动文件，不需要安装 Node.js。

**v0.3.0及更早版本需要手动升级这一次**：旧版先备份资料并关闭，v0.4.0解压到新目录，再复制旧版整个 `userdata` 到新程序旁，或在新版恢复备份。之后可通过内置更新中心升级，无需再手动去 GitHub 寻找和替换程序文件。

更新期间请关闭其他刷题标签页，不要关闭启动窗口。完成后仍使用原启动文件。内置升级保留的旧程序及备份会占用磁盘空间，请勿直接删除程序目录中的 `.app-versions` 或 `.app-current.json`。

## 其他发布文件

- `.842pack`：只含题库，当前题库仍为469条题目、287张裁切图。
- `.842answers`：独立公共答案包；本版尚无作者发布的答案，空包仅建立版本索引，不包含历史AI草稿。
- `zju842-updates.json`：程序自动读取的更新索引，使用者无需手动下载。
- Source code：供开发者自行构建，不是免安装成品。

下载仍需要访问 GitHub，网络故障时可继续离线刷题并稍后重试。首次运行可能出现系统来源提示，包未做商业代码签名。Windows和两种Mac均运行打包后启动及升级/失败回退测试；升级测试使用受控发布样例，不代表覆盖所有网络和系统环境。
