# v0.5.9：全题库结构化与简洁练习界面

## 本次更新

- **全题库结构化**：2009—2025年250组／469条题面采用文字、离线KaTeX公式及SVG图形，保留287张原题图供随时对照。
- **界面简化**：移除信号、数电章节卡片上的装饰图标；移除学科标题旁“已做／掌握”汇总块，侧栏与章节进度保留；移除做题页“原题说明”，仅保留“查看原图”。
- **连续练习**：专题最后一题的右箭头可直接进入下一专题或选择其他专题；整卷末题可查看本轮总结，不自动结束或打分。
- **显示修复**：修正目录悬停只高亮局部、夜间悬停配色及首页残留白色分隔线。
- **原记录保留**：章节、整卷和历史回看共用题面；原题ID、共享小问、答案、视频、收藏、自评、题单、计时和每轮记录仍按原编号关联。

## 如何更新

已有用户先更新程序至0.5.9，再安装题库r4。已经在本机试用r4的用户只需更新程序；新下载的Windows和macOS完整包已内置r4。公共答案维持r0，不包含测试照片或演示内容。

程序更新前会保留备份与旧程序。请勿删除原来的`userdata`，也不要用新包的空资料覆盖自己的文件夹。升级失败可按[恢复说明](https://github.com/burriedalien666/zju842-practice/blob/main/docs/old-version-recovery.md)处理。

本次结构化改造不改写原卷存在歧义的条件或连线。原图始终保留；相关来源疑点继续留在维护记录中，未视为已校订。
