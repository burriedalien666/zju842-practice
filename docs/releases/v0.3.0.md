# v0.3.0：章节选题、整卷练习与可靠保存

Windows、Mac Apple 芯片、Mac Intel 请分别下载对应 ZIP，完整解压后双击启动文件。无需安装 Node.js 或 Docker。

## 本次更新

- 按学科、章节、题型逐级选题，改善空章节返回、筛选切换及收藏、待复习、错题和题单的移除操作。
- 新增2009—2025年整卷练习、作答标记、小结和可自设日期的考研倒计时。
- 显示保存状态；失败后支持重试、导出与同标签页刷新恢复，多标签页发生冲突时阻止旧记录覆盖新记录。
- 修复导入空记录后的残留题目和整卷状态，改善题号复制、答案来源切换、草稿继续编辑及键盘切题。
- 保留个人答案照片、间隔复习、离线使用、个人资料备份和独立题库更新。

## 下载哪个文件

- `zju842-0.3.0-windows-x64.zip`：Windows 64位电脑。
- `zju842-0.3.0-macos-arm64.zip`：Mac Apple 芯片。
- `zju842-0.3.0-macos-x64.zip`：Mac Intel。
- `.842pack`：仅供已有程序导入题库资料，不包含程序升级。首次下载程序 ZIP 无需另下此文件。本次题目内容未变，仍为469条题目、287张裁切题图，尚无作者发布的题库答案。
- GitHub 自动附带的 Source code：面向自行构建的开发者，不是免安装程序。

## 从旧版升级

先确认旧版保存完成，导出“备份全部个人资料”，然后关闭旧版。新版解压到新目录后，在启动前将旧版 `userdata` 整个复制到新程序旁；或者在新版中恢复备份。不要覆盖旧目录，也不要同时运行两个程序操作同一数据目录。

确认收藏、题单、复习记录和个人答案都正常后再自行整理旧目录。回退请使用升级前保留的旧目录和备份。旧浏览器页面需关闭，通过新版启动器重新打开。

保存失败后的暂存仅用于本标签页刷新恢复，关闭前应重试保存或导出；跨标签页冲突不自动合并。

## 运行说明

三种平台均执行构建、自动化测试及打包后启动、题图读取、重启保存检查。包未做商业代码签名，首次运行可能出现系统来源提示；不要关闭系统整体安全保护。个人数据不包含在发布包中，也不会自动上传。
