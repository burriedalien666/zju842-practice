# v0.5.5：单题视频跳转与作者分批导入

本地功能交付版，未创建公开Release。最终功能随[v0.5.6](v0.5.6.md)发布；作者真实视频发布后，再关联并随题库更新下发。

## 功能与操作

- 保持原章节、题型、做题布局，只在有视频的题目下增加“视频”按钮；整卷练习同样支持。
- 列表只显示明确关联本题的作者讲解，不自动加入知识点、整章课程或第三方推荐。没有视频时不显示空入口。
- 在B站新标签页打开，保留当前题目；支持分P、起始时间和可选分段导航。
- 作者工具可读取公开BV视频的分P/完整合集元数据，按原题号分批预览和导入。默认不写入，确认后才保存。
- 重复批次不重复添加；错误题号、重复关联、非法URL或不完整公开目录会拒绝，避免只导入部分内容却宣称完整。
- 只存公开标题和链接，不下载视频，不读取密码、Cookie或私信。收藏夹里的视频可经浏览器读取少量公开链接作为临时测试，但不会进入正式题库。

## 资料与兼容

本次题库保持r2、公共答案r0，469题和287张题图不变，正式视频仍为空。作者视频元数据将随题库更新发布，不属于答案图片更新。含分段的新资料要求程序至少0.5.5。

现有收藏、复习记录、私人照片和题号不变。样例视频与完整程序分开存放，正式包不含测试关联。

维护方法见[作者视频维护](../video-guide.md)。后续操作与界面建议见[建议清单](../next-improvements.md)，未纳入本轮开发。
