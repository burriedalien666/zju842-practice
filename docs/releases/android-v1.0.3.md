## 主要功能

- 章节／知识点、历年真题、考点分析、收藏与题单练习，支持原图对照和日夜切换。
- 三档自评、普通练习计时、整卷轮次及按年份查看历史，重开可继续上次。
- 个人答案支持相册、拍照、旋转裁切、调序和删除撤销；本机备份恢复、分享副本。
- 程序、题库和公共答案独立更新；软件建议与题目纠错分别反馈。
- 奶蛋与展翅鹰图标，简洁的主题按钮及关于842页面。

## 本版流畅度改进

大范围选题复用自评映射，减少重复计算；自评、收藏和撤销时保留已展开的照片，不重复读取或重建。全文查找索引按需建立，关于页使用小尺寸无损图片。

在470条题目均有自评记录的隔离场景中，选题窗口同步处理平均耗时在Android11模拟器从约130ms降到56ms，Android15从约93ms降到32ms。此为同机页面事件测量，不是所有设备的物理屏幕延迟承诺。

## 升级注意

**先备份，再覆盖安装；不要卸载旧版或清除数据。** 已使用1.0.0—1.0.2可在App内检查程序更新，或下载APK覆盖。

从0.4.x测试版首次迁入时，请使用文件管理器打开APK，旧App内置更新器会拦截正式签名轮换。Android9及以上通过签名轮换接续资料，7/8使用兼容签名；如系统拒绝更新，保留原App与备份并反馈提示，不通过卸载绕过。

程序版本1.0.3、versionCode36；题库r4、公共答案r0、私人数据库schema4和备份format3保持。公共答案及正式视频暂未收录，安卓与电脑版个人备份格式不同。
