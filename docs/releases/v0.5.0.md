# v0.5.0：历年考点分析与双路径训练

## 新功能

- 新增历年考点分析：章节/具体知识点与年份矩阵，可切换涉及题量、是否考察、已核实分值；支持科目、年份区间、章节和考点搜索。
- 点击格子查看对应题目，进入刷题后可返回原分析条件；增加所选考点历年趋势与排行。
- 按所提供的2024年842统考考纲及教材目录重整18章、97个知识点、52类解题任务；“按知识点”和“按解题任务”分开选择。
- 综合题可涉及多个知识点；章节总量按主章节计一次，知识点行之间不可直接相加。469个原题号不变，个人答案和学习记录继续沿用。
- 单题、整卷题目和章节支持作者维护的B站讲解外链，可带分P和起始时间；没有视频时不显示空入口。普通用户不提供链接编辑功能。

## 数据说明

本版考点由现有题干摘要、标签、题型重新整理，并核对了部分综合原题；不是官方考点标注，也不声称已逐题完成全部原卷复核。

本版录入2025年27个题目/小题的明确分值，共150分，两科各75分，来源为原卷PDF第61—64页。其他年份尚未录入分值，显示“未标注”；2009、2024所提供整理卷未见明确分值。不能依据本版分值表比较完整历年分值趋势，也不把缺失当零分或预测未来命题概率。

视频功能已具备，但作者尚未提供实际视频链接；发布包不含演示链接或第三方冒充讲解。

## 怎样更新

v0.4.0用户在更新中心先完成“程序更新”，重启后再完成“题库更新 r2”，才能获得新的分类和知识点数据；公共答案仍为r0，没有新增答案图片。三类更新彼此独立。

新用户下载对应系统的完整ZIP后解压启动即可。v0.3.0及更早版本需手动下载程序并迁移 `userdata`。源码、Windows、Mac Intel及Mac Apple芯片下载包一同发布。
