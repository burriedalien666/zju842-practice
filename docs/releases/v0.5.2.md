# v0.5.2：本地连接状态与更新恢复

- 页面在使用期间检查本地服务，关闭启动窗口或服务断开后持续提示，不再等保存失败才发现；重新回到页面时也会检查。
- 更新中心连接失败时保留说明和“重新检查连接”“导出本页记录”入口，不再只弹出短暂的英文错误；断连时不把上次的更新数量当作当前连接状态。
- 区分本地服务断开、启动会话失效和 GitHub 更新下载连接失败；恢复连接不自动刷新、重发安装请求或覆盖未保存记录。
- 修复启动自动检查期间打开更新中心后，检查结束仍显示“正在检查”、按钮一直不可用的问题。
- 增加真实浏览器回归检查：停止服务、原页面检测断连、会话失效、重启服务、原页恢复未保存收藏。

## 已打开旧版页面的用户

旧页面不能自行启动已经关闭的本机程序。请先重新双击**原程序目录**的“启动题库”，保持启动窗口运行，并用原来使用的浏览器打开启动器生成的新页面。不要仅重输 `127.0.0.1:8843`，启动器链接还会建立本机会话。

若旧页面有未保存改动，先导出本页记录，不要关闭或刷新。新页面与旧页面地址端口相同、使用同一份资料时，回到旧页重试保存，再进行更新；端口或资料目录不同时先保留导出文件，勿直接覆盖另一份资料。

本次只更新程序至 v0.5.2，题库 r2、公共答案 r0 不变。Windows、Mac Intel、Mac Apple 芯片分别提供完整包。v0.4.0及以后使用免安装包的用户可在本地服务正常运行后通过更新中心升级；源码运行模式不支持替换自身程序包。

离线刷题不需要互联网，但需要本机题库程序保持运行。此版本不会在浏览器中安装常驻服务，也不能远程修复尚未启动的旧程序。
