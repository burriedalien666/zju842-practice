# v0.5.8 全题库结构化与连续练习

- 支持文字、KaTeX公式、SVG电路与图表组成的结构化题面，保留“查看原图”。
- 章节刷题、整卷练习和历史回看共用题面；收藏、自评、答案和视频仍绑定原题编号。
- 支持通过独立题库更新包安装结构化内容；程序更新和公共答案更新仍相互独立。
- 结构化题面加载或渲染异常时回退原图，不修改学习记录。

题库r4启用全部250组／469条结构化题面。来源疑点保留在折叠的“原题说明”与复核文档，不再因此回退整题截图。r4最低需要程序0.5.8；旧题库仍可在新程序中使用。

- 移除做题页常驻的复核备注条，保留按需查看的来源说明。
- 专题末题右箭头可直接选择下一专题或其他专题；整卷末题进入本轮总结，不自动结束或打分。
- 修复学科目录悬停高亮范围不完整、夜间悬停配色和首页残留分隔线。

本版本已在本机日常站完成迁移，尚未公开发布GitHub。跨平台正式发布另行执行。
