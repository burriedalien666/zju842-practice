# v0.5.6：本题视频、更新说明与完整看图

本次程序更新包含v0.5.5本地验收的视频功能，并补齐升级提示及图片查看调整。v0.5.5未公开发布；本地验收版可以正常发现v0.5.6更新。

## 新增与修复

- 做题页与整卷练习支持“视频”按钮，只显示作者明确关联本题的讲解，不展示知识点/章节课程推荐。没有视频时不出现空入口。
- 作者工具支持读取公开多P/完整合集、分批预览导入、去重与原题号校验；保留分P、起始秒数和分段导航。只保存公开元数据，不下载视频或获取登录凭据。
- 程序内升级完成并重启后显示一次“更新了什么”；题库、答案更新完成后的刷新也会显示资料变更说明。关闭后可在更新中心回看，不需要再次联网。
- 旧启动器完成新版激活也能显示本次程序摘要；失败回退不冒报成功。手动迁移到新目录不被误识别为自动升级，仍可从更新中心查阅当前版本说明。
- 移除看图窗口的再次“放大/缩小”与双向滚动。点击图片后按窗口完整显示，保留关闭返回、原题浏览与答案编辑；没有修改扫描图本身。
- 修复重复导入含分段链接时遗漏最低程序依赖的情况，拒绝返回错误视频或不完整分P目录，避免把部分清单当成完整导入。

## 内容与升级

- 正式题库保持r2、469题/287张图，公共答案保持r0。作者尚未录制正式视频，当前正式视频条目为0；收藏夹和公开合集测试视频不进入程序包。
- 当前界面不会凭空出现测试视频，作者后续关联视频并发布题库更新后，相关题目才显示入口。
- Windows x64、Mac Intel、Mac Apple分别提供完整包，旧程序可在更新中心检查；下载不通时按[迁移说明](https://github.com/burriedalien666/zju842-practice/blob/main/docs/old-version-recovery.md)使用新目录和资料备份，不覆盖运行中的目录。
- 学习记录、私人图片、原题号不变。新增通知已读状态只保存在本机，不上传个人数据。
