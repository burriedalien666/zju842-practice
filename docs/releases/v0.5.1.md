# v0.5.1：精简考点分析与保存断连恢复

## 考点分析更直接

- 默认显示近五年，首屏保留科目、章节/知识点和年份范围三个常用切换；一键可看全部年份。
- 去掉重复介绍、大统计卡和分析页的倒计时占位；自定义年份、分值、章节与名称搜索收进“更多筛选”，一次应用。
- 点章节名展开具体知识点；有题的格子可点击，无题格子不可误入。
- 单题直接进入，多题就地弹出题单，可选题或开始整组练习，不再强制滚到页面底部。
- 返回分析时保留筛选与选中位置；排行和趋势默认折叠，分值缺失与综合题统计说明保留。

## 保存提示与重试

本地服务停止或连接中断时，不再只显示英文 Failed to fetch，而是明确提示重新启动题库。服务重启导致会话失效、真正的版本冲突和磁盘失败分别提示。

未保存内容仍留在当前标签页。请打开启动器生成的新页面，建立会话后回到原页点击“重试保存”，不要先关闭或刷新原页；必要时先导出本页记录。“读取磁盘记录”明确标为放弃本页改动。

重试前先读取磁盘版本：若上次其实已保存但响应丢失，直接确认成功；若其他标签页有新记录，继续阻止覆盖，不强行合并。

## 更新

本次只需更新程序至v0.5.1。题库保持r2，公共答案保持r0，不重新分类、不改题图和分值、不触碰个人资料。

Windows、Mac Intel、Mac Apple芯片分别提供完整包。v0.4.0及以后可在更新中心升级；早期版本仍需手动迁移。启动窗口关闭后本地服务会停止，已有浏览器页面不能继续写入本机。
