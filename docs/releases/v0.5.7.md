# v0.5.7：单题界面、逐轮练习记录与进度修正

本次程序更新整合已在本地验收的界面与练习功能，并修正完成进度的统计和显示口径。

## 新增与改进

- 章节与整卷统一单题模式，保留原卷顺序；支持左右按钮／键盘切题、顶部题号网格及输入序号跳转。返回保留当前范围与列表位置。
- 精简为单行做题工具栏和900px上限题卡，统一线框图标；收藏用星星，自评保留“掌握／不熟／不会”一组，支持最近一次收藏或自评撤销。
- 日间／夜间模式记住选择，扫描题图保持原色；计时支持暂停和直接重置，不弹确认框，不清空自评或收藏。
- 新增“练习记录”，按年份回看每一轮的逐题自评、用时和原题；开始新轮会保留上一轮，未完成轮也可回看，已结束轮只读。
- 题图自动收起明显的边缘扫描留白，保留安全边距和原始文件；点击查看图片可切回原图。正文不因裁剪拉伸，私人答案照片不自动裁剪。
- 视频入口在每题下方保留；尚未录制或关联时提示“本题讲解视频待发布”，有链接时保留B站分P、时间点和新标签页跳转。

## 修复

- **完成进度统一按“已做题数／总题数”计算。** 23题中自评了3题显示13%（3/23），不再把已做题中1题掌握的33%当作章节进度；掌握、不熟、不会分别显示，不等同于试卷得分。
- 章节卡片、学科概览、目录和整卷进度使用一致含义；评为不熟或不会也计一次已做，重复改评不增加题量，未全部做完不因四舍五入显示100%。
- 修复进度开关与目录箭头重叠、悬停底色突变；目录折叠与进度显示互不干扰。
- 恢复“更多题目操作”中的题单加入／移出；修正返回收藏列表却打开首题、编辑个人答案后答案区折叠、考点分析返回位置丢失的问题。
- 修正刷新时计时保存的时序冲突，以及导入备份／放弃本页改动后旧计时缓存被带回；直接打开整卷链接正确建立新轮次。
- 练习历史按对应轮次的题目范围计数，旧版“已做但未自评”保留原意，不推断成掌握。

## 升级与资料

- 下载与你系统匹配的Windows x64、Mac Intel x64或Mac Apple arm64完整包，或在旧程序的更新中心升级。发布包自带运行环境。
- 题库仍为r2，469条题目、287张原图；公共答案仍为r0，正式视频条目仍为0。本次不发布测试题、测试视频或个人练习记录。
- 旧版当前轮会保留；更早已被旧版覆盖的轮次无法重建。旧轮没有用时的，续做只记录升级后的时间并明确标注。
- 个人照片、收藏、题单和历史学习资料保留。若需回退旧程序，请使用对应版本的升级前备份；不要把包含新轮次记录的备份反向导入旧版。
- 下载失败或旧版服务断开时，见[恢复与迁移说明](https://github.com/burriedalien666/zju842-practice/blob/main/docs/old-version-recovery.md)，不要覆盖运行中的目录。
