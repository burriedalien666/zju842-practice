## 从电脑版迁入

1. 在原电脑版“资料与备份”中点“备份全部个人资料”，保存生成的 `.sqlite` 文件。已有此功能的电脑版无需升级。
2. 将文件传到安卓设备，打开App“资料 → 从电脑版迁入 → 选择电脑备份”。
3. 核对资料摘要与冲突清单，确认后迁入。默认保留App已有的冲突内容，也可明确选择采用电脑内容。
4. 抽查照片、题单和练习记录，在App中再备份一次。

旧“导出记录”的JSON也能从同一入口迁入，但它本身不含照片。电脑原资料和导出的备份保留；相同资料重复导入不重复新增。

## 本版变化

- 迁入收藏、自评、题单、整卷练习历史、累计用时和个人答案照片；未结束的当前试卷可继续原题目范围。
- 同题草稿照片在前，定稿独有照片接在后面，共有照片编号去重。原始记录及草稿／定稿归属随App备份留存；电脑版专属复习计划不在App中执行。
- 已归档但未结束的旧轮次保持只读；缺失或部分计时明确标注，不把归档时间当完成时间。
- 每题最多12张照片、单张12MiB。合并超限、题号缺失、坏文件或暂存失效会提示，本次导入不提交。
- 私人数据库升级为schema5，保留原有资料。备份兼容format1—4，包含迁入原始记录、扩展轮次或更大照片时使用format4。

## 安装与备份

**先备份，再覆盖安装。** 已使用1.0.x可在App内检查程序更新，或从文件管理器打开APK覆盖；不要卸载旧版或清除数据。首次从0.4.x测试版迁入正式版，仍请使用文件管理器安装。

新版继续读取旧App备份。新增format4备份需要1.0.4及以上兼容版本恢复，请同时保留原电脑备份。

程序版本1.0.4、versionCode37，沿用正式签名。内置题库r4，250组／469条题面、287张原图；公共答案r0。题库和公共答案继续独立更新。
