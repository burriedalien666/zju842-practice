# 旧版无法更新时的恢复与迁移

旧客户端下载不到修复版时，可以先使用浏览器取得完整免安装包，再迁移资料；不必依赖已失败的旧下载器。源码ZIP不含运行环境，不能当作免安装包直接覆盖。

## 先保住未保存内容

若旧浏览器页面仍有未保存提示，先导出本页记录，不要刷新或关闭。重新运行原目录的启动器、在同一浏览器建立会话后再尝试保存。新页面端口或资料目录不同，不要默认它与旧页使用同一份数据。

## 一次性迁移

1. 从[官方发布页](https://github.com/burriedalien666/zju842-practice/releases)取得与你电脑匹配的完整程序ZIP，解压到新目录。检查版本和平台，不要把Source code压缩包当作免安装程序。
2. 在旧版保存完成并导出“备份全部个人资料”；未保存页的导出另行保留。
3. 关闭原题库启动窗口，确认服务停止后再复制资料，不能边写数据库边复制。不要结束其他项目的Node进程，也不要盲删锁文件。
4. 保留原安装目录不动，把**整份原userdata**复制到新包旁的userdata。不要只复制site.sqlite；独立题库、答案、指针及备份都可能在里面。不要手动删除WAL/SHM，不复制旧程序的.app-versions、.app-current.json或node_modules到新包。
5. 双击新包自己的“启动题库”，确认版本和资料目录。逐项检查收藏、题单、复习、整卷进度、私人照片草稿/定稿、公共答案与题图。
6. 确认无误后再改常用入口。旧目录与备份继续保留。若新版异常，停止新版再使用旧目录；新版新增记录应先导出，不把新版资料反向覆盖旧版。

使用自定义 `ZJU842_DATA_DIR` 时，验收应指向资料副本，不要让新旧实例同时写原库。若存在尚未完成的升级或损坏指针，先保留完整原目录和升级前备份，再处理恢复。

## 已使用本地验收版

本地验收目录与原个人资料目录相互独立，记录不会自动合并。看到没有旧收藏不表示丢失。需要迁移时，先确认哪份目录保存了应保留的记录，再按上面的步骤处理，不覆盖旧目录。

本次正式版使用v0.5.4，本地验收版v0.5.3可以正常发现升级。若旧实例仍无法连接下载源，按完整包手动迁移；先备份验收中产生的记录。
